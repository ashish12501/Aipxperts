Run Backend and Frontend (Windows PowerShell)

1. Open two PowerShell terminals.

2. Backend setup and run:
   cd D:\Aipxperts\Backend
   npm install
   Make sure .env includes:
   - MONGO_URI=<your_mongodb_connection_string>
   - JWT_SECRET=<your_jwt_secret>
   - PORT=5000 (optional, defaults to 5000)
   - FRONTEND_URL=http://localhost:5173 (optional)
   Start backend:
   npm start
   (Optional dev mode if nodemon is installed: npm run dev)

3. Frontend setup and run:
   cd D:\Aipxperts\ROMS-Frontend
   npm install
   Make sure .env includes:
   - VITE_API_BASE_URL=http://localhost:5000/
   Start frontend:
   npm run dev

4. Open the app:
   Frontend: http://localhost:5173
   Backend: http://localhost:5000
